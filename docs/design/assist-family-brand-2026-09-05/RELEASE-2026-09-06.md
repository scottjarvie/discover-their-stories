# Selected family branding

Scott approved these assets for adoption on 6 September 2026. The [selected package](selected-assets/README.md) contains editable SVG masters, monochrome variants, PNG exports, browser favicons, Apple-touch and installable-app icons.

The application favicon uses the selected identity. Existing header components and product palette tokens are preserved.

Plants uses current PL02 by default and retains last-pass PL03. Languages uses current LA01-R. Life carries the complete selected family, including Languages, Code and Hive, which have no matching local repositories.

Icon exports were checked against the approved masters. Nine existing applications passed local HTTP icon checks before this release; Life has static asset verification. Live deployment evidence is recorded by the release PR and GitHub deployments.
